# Credits

## Cuffed

MCA: Crime's physical-restraint, lock, transport, frisking and prison-equipment content is adapted
from **Cuffed** by **LazrProductions**.

- Repository: <https://github.com/LazrProductions/cuffed>
- Commit used: `48a336508abda1f4684bd337bc83199a212e5422`
- Licence: GNU General Public License v3.0, per the repository's `LICENSE` file and the GPL-3.0 badge
  in its `README.md`

Adapted from Cuffed: the restraint designs (handcuffs, shackles, tape, bundle hood and their worn
models), the lock, key, key-ring and key-mold designs, chains, fence and hook anchors and escort
transport, frisking, and the prison equipment — cell doors, safes, reinforced construction,
pillories, guillotines and bunks — together with the code and art itemised in
`docs/0.7.5/PROVENANCE.md`. Several further Cuffed items that were transferred during development
(bandage, knife, fork, spoon, prisoner tag, possessions box, fuzzy handcuffs, tray, poster, weighted
anchor, warden's guide, toilet) were removed again before release; section 5 of the provenance
manifest lists what was deleted.

The only attribution Cuffed's repository carries is `mod_authors=Lazr Productions` in its
`gradle.properties`; its git history has a single author, `lazrproductions`. There is no credits file
upstream, so no individual artist is named here. Cuffed's repository declares GPL-3.0 while its
`gradle.properties` declares `All Rights Reserved`; that discrepancy, and MCA: Crime's response to it
— every unattributed asset replaced by original MCA: Crime artwork or vanilla sounds — are recorded
in `docs/0.7.5/PROVENANCE.md`.
