# Clay and Leather mask refresh

Generated/edited with the built-in image generation tool, using the old sprites as edit targets and the newer masks as style references. The final masks use bold outlines and flat palettes sampled from the existing set: three opaque colors for Clay, four for Leather. Item sprites are exactly 16×16. The worn 128×64 atlases contain the identical 16×16 sprite at (16,16), matching the newer masks rather than stretching the face. Exterior pixels and eye holes are fully transparent; all other pixels are fully opaque.

The initial generated files depicted transparency as a checkerboard. A second image-generation edit replaced that with a magenta color key. Production conversion remapped each image to its requested palette without dithering, converted the color key to transparency, trimmed the exterior, and point-sampled the sprite to 12×12 inside a 16×16 canvas. Sampling offsets retain the small eyes and mouth. No smooth resampling or antialiasing remains in the assets.

Saved assets:
- `src/main/resources/assets/mcacrime/textures/item/clay_mask.png`
- `src/main/resources/assets/mcacrime/textures/item/leather_mask.png`
- `src/main/resources/assets/mcacrime/textures/models/armor/clay_mask_layer_1.png`
- `src/main/resources/assets/mcacrime/textures/models/armor/leather_mask_layer_1.png`

The Mask Station's decorative mask and empty preview already reference the Clay sprite and inherit this refresh.
