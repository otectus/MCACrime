# Mask texture generation

Generated with the built-in image generation tool. Item PNGs are sampled to exactly 16×16 without smoothing. Worn textures use a 128×64 armor atlas so the front face retains 16×16 pixels; only the head's front UV region (16,16 to 31,31) contains the trimmed mask. All other regions are transparent, leaving the sides, top, and back of the head uncovered. The existing armor model supplies the offset from the face; the generated rim shading supplies the visual depth.

## Clay Mask

Use case: stylized-concept. Asset type: Minecraft inventory item texture. Create ONE isolated front-facing full-face mask sprite on a genuinely transparent background. Strict authentic Minecraft 16x16 pixel art: composition is exactly a 16 by 16 logical grid, enlarged with nearest neighbor, each logical pixel a large perfectly solid square. No fine details smaller than one grid cell, no antialiasing, no gradients. Mask centered within grid columns 3 through 12 and rows 1 through 14, angular squared-off oval silhouette covering forehead, cheeks, nose and chin. Thin one-pixel bevel shading gives slight depth while facing straight forward, symmetric frontal view, no rotation. This is a shallow face plate, not a helmet, no head, no ears, no hood, no straps extending around a head. Face is drawn/painted onto the opaque material: two simple dark charcoal eyes and a small hand-drawn dark curved mouth, readable and slightly uncanny but neutral. The eyes and mouth are pigment, not holes. Restrained palette with 5 material shades plus charcoal paint. No text, no labels, no background, no cast shadow outside sprite. Deliver a square transparent PNG, preferably native 16x16; if larger, faithfully enlarge the exact 16x16 pixel grid. Material: pale gray-beige unfired clay, matte chalky surface, light upper-left rim and darker gray taupe lower/right edge. Very sparse chunky pixel mottling. No cracks or additional ornaments.
